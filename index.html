Studi Kasus: Perencanaan Pengadaan Laptop

Skenario:
Satuan Kerja Pusdiklat ABC membutuhkan laptop untuk kebutuhan Widyaiswara. Saat ini (Tahun 2025) tersedia 25 unit laptop kondisi baik. Karena ada penambahan 3 Widyaiswara baru, dibutuhkan tambahan 3 unit laptop lagi.

Tugas Anda:
Lakukan identifikasi kebutuhan untuk Tahun Anggaran 2026 dengan mengacu pada formulir di bawah ini. Perhatikan data berikut:

  • Spesifikasi: Prosesor min. Core i5, RAM 16GB, SSD min. 500GB.
  • Anggaran: Program Dukungan Manajerial, KRO Layanan Sarana Internal.
